# LMS Project — Система управления курсами

Это Django-проект для создания платформы онлайн-обучения.  
Позволяет добавлять **курсы** и **уроки**, управлять ими через REST API.

---

## 🧩 Функционал

- CRUD для **курсов**
- CRUD для **уроков**
- Уроки привязываются к курсам
- Работа с данными через JSON API
